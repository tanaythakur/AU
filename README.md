# Cricket Academy & Sports Arena Management (Phase 1)

Admin-only management app. Stack: React + Vite, Tailwind CSS v4, React Router, Supabase,
TanStack Query, React Hook Form + Zod, Recharts, Lucide, date-fns.

## Run
    npm install
    cp .env.example .env   # fill in Supabase URL + anon key
    npm run dev

Path alias: `@` -> `src`. Design tokens live in `src/styles/tokens.css`.
